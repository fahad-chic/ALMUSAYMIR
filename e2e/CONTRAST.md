# فحوصات تباين الألوان (WCAG AA)

هذا الفحص التلقائي يمنع عودة مشاكل وضوح النصوص (مثل النص الداكن على خلفية
داكنة) في مشروع «أناقة ROOZ».

## المعيار
WCAG 2.1 AA:
- **4.5:1** للنص العادي (أقل من 24px، أو أقل من 18.66px غير عريض).
- **3:1** للنص الكبير (≥24px، أو ≥18.66px بوزن ≥700) ولعناصر الواجهة/الأيقونات.

## المكوّنات
| الملف | الدور |
|---|---|
| `src/utils/wcag.js` | دوال حساب النسبة الصرفة (parse/luminance/ratio/blend/threshold). |
| `src/utils/wcag.test.js` | اختبارات وحدة للدوال (تعمل ضمن `npm test`). |
| `e2e/contrast-audit.mjs` | تدقيق حقيقي عبر متصفح على الموقع المبنيّ. |
| `.github/workflows/ci.yml` → وظيفة `contrast` | يشغّل التدقيق في CI ويفشل عند وجود مخالفة مؤكدة. |

## التشغيل
```bash
npm run build
npm run preview -- --port 4173   # في طرفية أخرى
BASE_URL=http://localhost:4173 npm run contrast

# فحص صارم يُفشل أيضًا على الحالات المشكوكة (خلفيات متدرجة/شفافة)
BASE_URL=http://localhost:4173 npm run contrast:strict
```
خيارات: `--base <url>`، `--strict`، `--max <n>` (عدد المخالفات المسموح، افتراضيًا 0)،
`--json <path>`، ومتغيّر `WCAG_ROUTES` لتحديد المسارات.

## ما يُفحَص فعليًا
- النصوص المباشرة، الحقول (`input/select/textarea`) و`placeholder`،
  والأيقونات داخل الأزرار/الروابط بلا نص.
- حالات `:hover` و`:focus` لعناصر التفاعل.
- على الصفحات المهمة (الدخول، التسجيل، الاتصال، FAQ، الصفحة الرئيسية،
  الفروع، الموظفون، الإعلانات، حراج، الكتالوج، ...).

## الحالات التي **لا** يمكن الحكم عليها آليًا (تُسجَّل كـ «suspects/skipped»)
1. **الخلفيات المتدرجة (linear/radial gradient)** — لون الخلفية الفعلي خلف
   النص غير معروف بدقة عند نقطة النص، لذا تُستبعد بدل إعطاء نتيجة خاطئة.
   (هذا سبب استبعاد عنوان `FAQ` مثلًا.)
2. **الخلفيات نصف الشفافة (alpha < 0.95)** وعناصر فوق الصور — يعتمد التباين
   على ما خلفها.
3. **طبقات الزينة** (`pointer-events:none`) والنصوص الخفيّة/بحجم صفر
   (قوائم مغلقة، أيقونات مخفية).
4. **العناصر المعطّلة** (`disabled`/`aria-disabled`) — مستثناة من متطلبات AA.
5. **`placeholder`** — معفى من 1.4.3 عند وجود تسمية (label) مرئية للحقل،
   لذا هو ضمن قائمة الاستثناءات الموثّقة (`BASELINE` في السكربت).

## الاستثناءات الموثّقة (`BASELINE`)
قائمة صغيرة داخل `e2e/contrast-audit.mjs` تضم الحالات المعروفة المقبولة، كل
واحدة بسبب مكتوب. تُبقى ضئيلة، وأي إضافة تتطلب مبررًا.

## ملاحظات أداء
- يتوقف الفحص تلقائيًا في حال انتهاء مهل الجوال الثقيلة، ويطبع تقريرًا JSON في
  `e2e/report/contrast-audit.json` (متجاهَل في Git) ويُرفَع كأرتيفاكت في CI.
- لا يعدّل هذا الفحص أي تصميم أو لون أو مسار؛ فهو رقابي فقط.
